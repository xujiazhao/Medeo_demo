# User demo assets

Drop your own editing material here. The prototype remains usable without these files; generated demo assets are used as fallbacks.

Recommended filenames:

- `source-01.mp4`
- `source-02.mp4`
- `source-03.mp4`
- `source-cover.jpg`
- `brand-logo.svg`
- `music-bed.mp3`

The front-end intentionally does not upload these files anywhere.
