# Medeo Pro 创作空间 — 前端优化 Demo 工作计划

## 1. 项目目标

做一套无后端、可在面试现场稳定演示的高保真前端 Demo。它不是重新画一套皮肤，而是验证一个明确的产品判断：

> 专业 AI 视频工具的核心不是“让用户更快按下生成”，而是让人和 Agent 在同一份创作文档上逐步达成共识、控制成本，并在长任务期间持续工作。

Demo 要修复五类问题：

1. 模糊聊天输入可能直接触发长耗时、高成本生成。
2. 产品偏“一键生成玩具”，缺少专业创作者的素材与项目工作流。
3. 界面容器、边框和背景层次过多，聊天与编辑区长期争夺注意力。
4. 长任务的工具日志挤占主对话，生成期间缺少可继续讨论的通道。
5. 文档只是生成结果的附件，没有成为上下文、决策和版本的中枢。

## 2. 目标用户

### A. 轻量创作者

- 输入一个模糊想法，希望 Agent 帮他逐步明确内容、平台、时长和风格。
- 对生成模型和成本不熟悉。
- 需要在执行前看到方案和预计消耗，并明确确认。

### B. 专业剪辑师 / 内容团队

- 已有采访、B-roll、品牌素材、字幕、音乐或脚本。
- 希望 AI 阅读素材、建立素材语义索引、协助粗剪和后期，而不是全盘替代。
- 需要版本、文档、镜头状态、可追溯的 Agent 操作和可打断的任务。

### C. 创意策划 / 导演

- 主要在脚本、受众、节奏、分镜和修改意见上工作。
- 希望生成运行时继续讨论下一版，而不是被工具日志占满对话。

## 3. 产品原则

1. **确认优先**：不可逆或高成本步骤前必须有清晰的确认门。
2. **文档先行**：brief、脚本、分镜和剪辑计划是项目状态，不是聊天附件。
3. **素材优先**：先理解已有内容，再决定生成、补拍、剪辑或后期。
4. **渐进执行**：先低成本分析和草案，再按镜头批准昂贵生成。
5. **注意力自适应**：界面根据用户当前意图把聊天或工作区提升为主舞台。
6. **运行不阻塞**：Agent 在后台工作时，用户仍可编辑文档，并在右侧创建独立 Conversation Session。
7. **结果与日志分离**：主界面展示决策和产物，工具细节收进可展开的 Activity。

## 4. 核心信息架构

### 首页

- 主要入口从底部小输入框改为两个明确动作：
  - `从想法开始`：进入循序渐进的方案澄清。
  - `从素材创建空间`：以预置案例演示专业用户的素材驱动项目。
- Recipes 退居“灵感与模板”，不再成为唯一显眼的创作入口。

### 创作空间

- **左侧 Project Browser**：文档、任务与 Activity 在上；分隔线下是视频、图片、音频。初次进入只出现当前项目的唯一《视频方案》文档。
- **中央 Stage**：播放器与时间线保持为稳定工作面；左侧内容点击后用浮层放大预览，不替换整套工作台。
- **右侧 Copilot**：当前决策对话，默认不展示冗长工具日志。
- **Conversation Sessions**：在右侧 Copilot 中切换或新建独立讨论，用于下一版、标题和发布计划，不改变正在运行的任务。
- **Activity**：作为左侧一级内容展示后台任务、重试、成本和版本变化，不再使用浮窗。

## 5. 关键交互流程

### Flow A：从明确想法到可编辑方案

1. 用户提出“高跟鞋御姐在 Home Bar 讲男生怎么追女生”的抖音方向。
2. 聚焦对话先确认核心判断、素材策略和传播动作；每轮都支持快捷方向与自由输入。
3. AI 在回答之间展示简短的创作判断，让用户看到观点如何影响开场、镜头和结尾。
4. 三轮讨论汇成《美女教你谈恋爱 · 视频方案 v1》；用户确认后文档落到左侧，对话滑向右侧，中央播放器与时间线同时进入。
5. 文档明确角色、四段已有素材、40 秒镜头结构和首版剪辑约束。
6. 右侧对话默认展开，Agent 在约 20 秒内生成四段 Home Bar 视频，并行准备旁白、重点字幕与 BGM，随后组装 40 秒粗剪。
7. 用户放大预览文档或素材时，中间工作区与右侧对话保持原位。

### Flow B：专业素材驱动剪辑

1. 首页选择“从素材创建空间”，直接进入 Focus 分析状态；面试 Demo 跳过真实上传。
2. Agent 自动阅读 4 段预置户外灯素材，依次识别使用场景、便携产品卖点和可用镜头。
3. Agent 判断目标为线上电商产品宣传片，自动整理为 `25 秒 · 9:16 · 电商种草` 执行单。
4. 确认卡明确复用全部已有素材、不新增画面，并列出旁白、BGM、卖点字幕和粗剪四项任务。
5. 用户确认后进入工作台；《户外氛围灯 · 产品视频方案 v1》落到左侧，右侧 Agent 默认展开并立即开工。

### Flow C：长任务不中断协作

1. 主任务进入自动后期：旁白、BGM、字幕与粗剪按依赖推进，不生成多余镜头。
2. 右侧显示统一任务图和每个节点状态，不再重复 `Tasks(0/4)` 等矛盾信息。
3. 用户通过右侧顶部 `+` 新建独立 Session，讨论下一版封面、标题和发布文案。
4. Session 中的建议可保存为文档，但不会修改当前任务。
5. 后台发生重试时，Activity 清晰显示原因、影响与恢复状态。

### Flow D：稳定工作区与可控面板

- 聚焦对话：Live Brief 跟随视口，输入框固定在底部；不模糊任何内容。
- 进入工作区：左侧文档、中央播放器/时间线、右侧对话形成稳定三栏关系。
- 左右栏都可独立拖动宽度；只高亮当前正在拖动的一侧，拖拽位置实时跟随鼠标。
- 右侧收起时只保留靠上对齐的 Copilot 与 `+`；展开时通过 dropdown 切换 Session。

## 6. Demo 场景与演示脚本

### 3–5 分钟主线

1. 首页选择“从一个想法开始”，进入聚焦对话。
2. 展示原始需求：高跟鞋御姐在 Home Bar 做抖音情感解说。
3. 通过三轮点击或自由输入，依次锁定核心判断、四段镜头的生成方式和传播动作。
4. 确认视频方案；观察 Live Brief/对话连续动画进入左、右栏，中央工作区出现，Agent 自动开始工作。
5. 点击左侧唯一文档，放大查看角色设定、四张首帧、四段镜头和旁白结构。
6. 切换到视频栏，点击任一素材使用原生播放器预览，不离开工作区。
7. 返回首页进入“从素材创建空间”，展示 4 段灯具素材的全自动理解、一次确认和 25 秒产品片工作台。

## 7. 视觉策略

- 沿用 Medeo 的深色基调、Manrope/Nohemi 和紫色品牌色，保证改版有延续性。
- 减少永久边框：以一个主平面、弱分隔线和焦点明暗取代“卡片套卡片”。
- 只保留三层 surface：背景、工作面、浮层。
- 统一圆角与间距；减少不一致的 15/20/25/36px 半径。
- 动态变化服务于状态迁移：聚焦对话进入工作区时有连续空间动画；工作区内容始终保持清晰可读，不使用模糊。
- 文档使用更接近编辑器的排版与留白，提升专业感和可读性。

## 8. 前端实现范围

### 必做

- 无依赖静态前端，可本地一条命令运行。
- 首页 / 创作空间两个主视图。
- 想法讨论、自动素材理解、执行确认三个 Focus 状态。
- 素材、Docs、时间线、播放器的模拟数据。
- Chat / Focus / Edit / Run 四种布局模式。
- 主任务图、Activity、多对话 Session。
- 文档创建、切换、简单编辑和保存状态。
- 模拟任务进度与自动重试。
- 支持使用 `assets/demo/` 中两套固定案例素材；主演示链路不要求也不展示真实上传。

### 暂不做

- 真实模型或上传后端。
- 真实视频解码、转码、时间线渲染和导出。
- 多人协作、权限和云同步。
- 完整移动端编辑体验。

## 9. Demo 数据与素材规范

- `assets/demo/`：两套案例——4 段 9:16 Home Bar 视频、对应首帧与角色设定图；4 段便携户外灯产品视频。
- 恋爱案例把 Home Bar 文件作为 AI 生成结果，在前端模拟约 20 秒生成过程；灯具案例把户外灯文件作为用户已有素材。
- `src/demo-data.js`：项目、文档、素材、任务和消息的唯一模拟数据源。
- 所有长任务使用确定性计时器，刷新后可重置，避免面试现场随机失败。

## 10. 验收标准

- 聚焦对话同时支持自由输入和快捷方向，不将用户锁在固定选项中。
- 对话、Live Brief 与工作区之间通过连续空间动画完成重排。
- 用户能在 10 秒内理解当前项目阶段、下一步和预计成本。
- 主任务运行时可以在右侧创建并切换独立 Conversation Session。
- 用户在聊天与编辑之间切换时，视觉焦点明显且没有丢失上下文。
- Docs 是可见、可切换、可编辑的第一等对象。
- 界面不出现重复或矛盾的任务进度。
- 1440px 与 1728px 宽屏均能完整演示，1200px 下有合理降级。

## 12. 后续可扩展方向

- 接入真实字幕/镜头识别输出。
- 用 WebCodecs 或现成时间线组件替换静态轨道。
- 将文档模型升级为结构化 schema，并支持版本 diff。
- 记录真实任务成本和耗时，用于执行前预测与执行后复盘。
